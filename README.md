# Machine Learning-Based Economic Regime Discovery

An unsupervised machine learning project for identifying economic growth patterns using clustering and dimensionality reduction techniques.

## Machine Learning Techniques

- K-Means Clustering
- Hierarchical Clustering
- DBSCAN
- Principal Component Analysis (PCA)
- Silhouette Score
- Davies-Bouldin Index
- Feature Standardization
- Outlier Detection
- Winsorization

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- SciPy
- Matplotlib
- Seaborn

## Project Workflow

1. Data ingestion
2. Data quality validation
3. GDP growth-rate feature engineering
4. Standardization
5. Outlier detection and treatment
6. Exploratory data analysis
7. PCA dimensionality reduction
8. K-Means clustering
9. Hierarchical clustering
10. DBSCAN clustering
11. Model evaluation and comparison

## Disclaimer

This project uses sample/demo economic data for educational and portfolio purposes. Results should not be interpreted as real-world economic or policy conclusions.
